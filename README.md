# 魔女のポーション工房

月夜の工房で薬瓶のポーションを注ぎ分けるウォーターソートパズルです。スマホとPCのブラウザで遊べます。

- 全500レベル(巨大ボトル・ブラインド・カーテンのステージを含む)
- ポーション図鑑、実績、デイリーチャレンジ、ミニゲーム3種
- 進捗は遊んでいる端末のブラウザに保存されます

## ホーム画面に追加して遊ぶ

iPhone: Safariでページを開き、共有ボタンから「ホーム画面に追加」を選ぶと、ブラウザの枠なしで遊べます。

## このフォルダについて

GitHub Pages でそのまま公開できる形になっています。ソースは制作用フォルダの `web/` にあり、`web/tools/build.sh` でこのフォルダを作り直します。

## 音源について

- BGM: [こんとどぅふぇ](https://conte-de-fees.com/)(シルフの森、妖精たちの演奏会、宵闇の妖精、やったー!)
- 効果音: [効果音ラボ](https://soundeffect-lab.info/)

BGMはゲーム内でのみ再生できる形式に変換して置いています。音源ファイルとしての再配布はできません。利用条件は各サイトの規約に従います。
